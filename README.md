# 구구단 놀이터

초등학생이 놀이를 하면서 구구단 2~9단 72문제를 빠짐없이 연습하는 웹 페이지예요. 설치 없이 브라우저에서 바로 할 수 있어요.

**바로 하기:** https://gusrl0613.github.io/gamegugudan/

## 놀이

| 놀이 | 하는 방법 |
| --- | --- |
| 풍선 터뜨리기 | 답이 적힌 풍선이 날아가기 전에 눌러요. 하트 3개가 다 없어지면 끝나요. 5문제를 맞힐 때마다 풍선이 빨라져요. |
| 몬스터 대결 | 시간 안에 답을 쓰면 몬스터를 공격해요. 틀리거나 시간이 다 되면 몬스터가 공격해 하트가 줄어요. 몬스터를 물리칠수록 더 강한 몬스터가 나와요. |
| 두더지 잡기 | 정답을 든 두더지를 눌러요. 엉뚱한 두더지를 누르면 3초가 줄어요. 60초 동안 몇 마리를 잡는지 겨뤄요. |
| 60초 도전 | 숫자를 누르면 바로 채점돼요. 60초 동안 몇 문제를 맞히는지 겨뤄요. |
| 짝 맞추기 | `7 × 8` 같은 문제 카드와 `56` 같은 답 카드를 뒤집어 짝을 찾아요. 모두 세 판이에요. |
| 구구단 표 | 소리 내어 읽으며 외우고, '답 가리기'로 다 외웠는지 확인해요. |

## 문제가 나오는 방식

- **자동(기본):** 아직 도장을 못 받은 문제가 먼저 나와요. 2·3·4단부터 시작해서, 한 단을 다 맞히면 다음 단이 들어오는 식으로 늘어나요. 그래서 계속 풀다 보면 72문제를 빠짐없이 한 번씩 풀게 돼요.
- **직접 고르기:** 고른 단에서만 문제가 나와요.
- 틀린 문제는 '다시 볼 문제'가 되어 자주 다시 나오고, 맞히면 빠져요.

## 채점

- 숫자를 쓰는 놀이(60초 도전, 몬스터 대결)는 답의 자릿수만큼 누르면 바로 채점하고 다음 문제로 넘어가요.
- 맞으면 초록색, 틀리면 쓴 답이 빨간색으로 보이고 정답과 외우는 말("칠팔 오십육")을 알려 줘요.
- 모르는 문제는 '모르겠어요'를 누르면 정답을 보여 줘요.

## 로그인과 포인트

- 처음 들어올 때 **이름과 암호(숫자 4~8자리)** 를 넣어요. 처음 쓰는 이름이면 새로 만들어지고, 다음부터 같은 이름과 암호로 들어오면 포인트와 도장이 이어서 쌓여요.
- 한 번에 맞히면 10P, 연속으로 맞히면 최대 20P까지 올라가요. 처음 맞힌 문제는 도장과 함께 5P를 더 받아요. 몬스터를 물리치면 30P, 짝 맞추기 한 판을 끝내면 20P를 더 받아요.
- 포인트가 쌓이면 칭호가 바뀌어요: 구구단 새싹 → 꼬마 탐험가(200P) → 탐험가(600P) → 기사(1,200P) → 마법사(2,500P) → 박사(5,000P) → 왕(10,000P)
- 손님으로 하면 포인트가 저장되지 않아요.

### 포인트가 저장되는 곳

| 설정 | 저장되는 곳 | 특징 |
| --- | --- | --- |
| 기본 (설정 없음) | 학생이 쓰는 기기의 브라우저 | 바로 쓸 수 있어요. 같은 기기에서만 이어지고, 다른 기기에서는 처음부터예요. |
| 구글 시트 연결 | 선생님의 구글 시트 | 어느 기기에서 들어와도 이어져요. 선생님이 시트에서 학생별 포인트·도장 수·마지막 접속을 볼 수 있어요. |

## 선생님용: 구글 시트에 포인트 저장하기

한 번만 하면 돼요. 10분 정도 걸려요. 학교 계정보다 **개인 Gmail 계정**을 권해요(학교 계정은 관리자 설정 때문에 학생이 접속하지 못할 수 있어요).

1. [구글 시트](https://sheets.google.com)에서 빈 스프레드시트를 새로 만들어요. 이름은 "구구단 놀이터 포인트"처럼 정하면 돼요.
2. 메뉴에서 **확장 프로그램 → Apps Script**를 눌러요.
3. 원래 있던 코드를 모두 지우고, 이 저장소의 [`apps-script/Code.gs`](apps-script/Code.gs) 내용을 통째로 붙여 넣은 뒤 저장(디스크 아이콘)해요.
4. (선택) 아무나 새 이름을 만들지 못하게 하려면 코드 위쪽의 `var JOIN_CODE = '';`에 반 코드를 넣어요. 예: `var JOIN_CODE = '3반2026';` 학생은 처음 이름을 만들 때 이 코드를 넣어야 해요.
5. 오른쪽 위 **배포 → 새 배포**를 누르고, 톱니바퀴에서 **웹 앱**을 골라요.
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
6. **배포**를 누르고 권한을 승인해요. "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)(으)로 이동**을 눌러 허용해요. 내가 만든 코드라서 괜찮아요.
7. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해요. 주소창에 붙여 넣어 열었을 때 `{"ok":true,"app":"gugudan"}`이 보이면 잘 된 거예요.
8. 이 저장소에서 [`config.js`](config.js)를 열고 연필(편집) 버튼을 눌러 `sheetUrl: ""`의 따옴표 안에 그 주소를 붙여 넣은 뒤 **Commit changes**를 눌러요.
9. 1~2분 뒤 사이트를 새로 고침해서, 로그인 화면 아래에 "선생님의 구글 시트에 저장돼요"가 보이면 연결된 거예요.

학생이 처음 로그인하면 시트에 **학생** 탭이 생기고, 한 줄에 한 명씩 쌓여요.

### 시트에서 할 수 있는 일

- **암호를 잊은 학생:** 그 학생 줄의 '암호 해시' 칸을 지우면, 학생이 다음에 넣는 암호가 새 암호가 돼요.
- **포인트 고치기:** '포인트' 칸 숫자를 바꾸면 돼요.
- **학생 지우기:** 그 줄을 삭제하면 돼요.
- `Code.gs`를 고쳤다면 **배포 → 배포 관리 → 편집 → 새 버전**으로 다시 배포해야 반영돼요.

### 알아 둘 점

- 첫 화면의 **포인트 순위**에는 이름과 포인트가 보여요. 사이트 주소를 아는 사람은 누구나 볼 수 있으니, 실명보다 **번호+별명**(예: "15번 하늘")을 쓰게 해 주세요. 순위를 숨기려면 `config.js`의 `showRanking`을 `false`로 바꿔요.
- 암호는 아이들이 친구 계정에 들어가지 않게 막는 정도의 장치예요. 중요한 개인정보는 넣지 마세요.
