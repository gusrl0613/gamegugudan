# 구구단 놀이터

초등학생이 놀이를 하면서 구구단(2~9단)을 연습하는 웹 페이지예요. 설치나 로그인 없이 브라우저에서 바로 할 수 있어요.

**바로 하기:** https://gusrl0613.github.io/gamegugudan/

## 놀이

| 놀이 | 하는 방법 |
| --- | --- |
| 풍선 터뜨리기 | 답이 적힌 풍선이 날아가기 전에 눌러요. 하트 3개가 다 없어지면 끝나요. 5문제를 맞힐 때마다 풍선이 빨라져요. |
| 60초 도전 | 숫자 버튼이나 키보드로 답을 써요. 60초 동안 몇 문제를 맞히는지 겨뤄요. |
| 구구단 표 | 소리 내어 읽으며 외우고, '답 가리기'로 다 외웠는지 확인해요. |

- 시작 화면에서 연습할 단을 골라요. 여러 단을 함께 골라도 돼요.
- 답을 맞히거나 틀리면 "칠팔 오십육"처럼 외우는 말을 함께 보여 줘요.
- 틀린 문제는 같은 판에서 다시 나오고, 결과 화면의 **틀린 문제만 연습**으로 따로 풀 수 있어요.
- 최고 기록은 그 기기의 브라우저에만 저장돼요.

## 파일

`index.html` 하나에 모든 내용이 들어 있어요. 내려받아서 더블클릭해도 실행돼요.
